# monigrus

crie um sistema de monitoramento de grupos com as seguintes funcionalidades da imagem enviada;
menu lateral com os seguintes campos; dashboard, hub do colaborador, anomalias, Monitotamento, conexões, configurações, sair.
dark mode e light mode.
importante: adicione conteudo apenas na pagina de "Monitoramento".
